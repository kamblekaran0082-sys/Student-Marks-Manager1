# Student Marks Manager

This is my first Python project.

I made this project to practice the Python concepts I have learned so far.

## What does this project do?

This program takes the student's:
- Name
- Python marks
- SQL marks
- ML marks

Then it calculates:
- Total marks
- Average
- Pass or Fail
- Grade
- Highest marks
- Lowest marks

## Python concepts I used

- Variables
- Input
- Lists
- Dictionaries
- If / elif / else
- While loop
- Try / except
- Functions
- Basic Python built-in functions

## How the program works

First, the program asks for the student's name and marks.

The marks are stored in a list inside a dictionary.

Then I use a function to calculate the total, average, result, grade, highest mark, and lowest mark.

Finally, the program displays the result.

## Example

```text
Student: Karan
Python: 80
SQL: 75
ML: 90
Total: 245
Average: 81.67
Result: Pass
Grade: B
Highest: 90
Lowest: 75
```
